# Application Lycée Louis Blériot

## Lycée Louis Blériot

### Dépôt GitHub du projet

Le code source et la documentation du projet sont disponibles sur
le dépôt GitHub :

**GitHub :** [app-lycee-louis-bleriot](https://github.com/TON-PSEUDO/app-lycee-louis-bleriot)

## Présentation du projet

Ce projet a pour objectif de créer une application Android pour le
Lycée Louis Blériot.

L'application permet d'avoir un accès direct au site officiel du
lycée et de proposer des QCM permettant aux élèves de réviser leur
filière.

---

## Objectifs du projet

- Donner un accès direct au site officiel du lycée.
- Permettre aux élèves de réviser leur filière.
- Proposer des QCM adaptés aux différentes filières.
- Permettre de voir directement la correction.
- Donner une explication après chaque réponse.
- Afficher le score obtenu.
- Sauvegarder le meilleur score.
- Garder le nombre de QCM réalisés.
- Ajouter progressivement de nouveaux QCM.

---

## QCM disponibles

Les QCM sont organisés par filière.

### 1. Bac Pro CIEL

**Cybersécurité, Informatique et réseaux, Électronique**

Cette filière est actuellement disponible dans l'application.

Le QCM est séparé en 5 parties :

- Réseaux
- Cybersécurité
- Programmation
- Systèmes
- Électronique

---

### 2. Bac Pro MELEC

**Métiers de l'Électricité et de ses Environnements Connectés**

Le QCM MELEC est prévu pour une prochaine version.

Il pourra notamment porter sur :

- l'électricité ;
- les installations électriques ;
- les équipements électriques ;
- les automatismes ;
- les systèmes connectés.

---

### 3. CS Cybersécurité

**Certificat de spécialisation Cybersécurité**

Le QCM de cybersécurité est prévu pour une prochaine version.

Il pourra notamment porter sur :

- la sécurité informatique ;
- les réseaux ;
- les menaces informatiques ;
- les vulnérabilités ;
- la protection des systèmes.

---

### 4. Autres filières...

De nouveaux QCM pourront être ajoutés par la suite.

---

## Fonctionnalités

- Accès direct au site officiel du lycée.
- QCM organisés par filière.
- Questions mélangées.
- Correction après chaque réponse.
- Explication de la réponse.
- Barre de progression.
- Score final.
- Meilleur score sauvegardé.
- Nombre de QCM réalisés.
- Possibilité de recommencer un QCM.

## Technologies utilisées

### Android Studio

Android Studio est utilisé pour développer l'application Android.

### Kotlin

Le langage Kotlin est utilisé pour programmer l'application.

### Jetpack Compose

Jetpack Compose est utilisé pour créer l'interface de l'application.

### SharedPreferences

SharedPreferences est utilisé pour sauvegarder certaines données
localement, notamment les scores et le nombre de QCM réalisés.
