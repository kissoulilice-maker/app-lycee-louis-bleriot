# App Lycée Louis Blériot

Application Android créée pour le Lycée Louis Blériot.

## But de l'application

### Accès au site officiel du lycée

### Révision pour les différentes filières avec des QCM

Les QCM sont organisés par filière.

#### QCM disponibles

- **Bac Pro CIEL**
  - Réseaux
  - Cybersécurité
  - Programmation
  - Systèmes
  - Électronique

- **Bac Pro MELEC**
  - QCM à venir

- **CS Cybersécurité**
  - QCM à venir

## Fonctionnalités

- Accès direct au site officiel du lycée
- QCM par filière
- Questions mélangées
- Correction après chaque réponse
- Explication de la réponse
- Score final
- Meilleur score sauvegardé
- Nombre de QCM réalisés

## Site du lycée

https://lyc-bleriot-trappes.ac-versailles.fr/

## Technologies

- Kotlin
- Jetpack Compose
- Android Studio
- SharedPreferences
